# FreeShip Threshold

Веб-калькулятор порога бесплатной доставки. Самостоятельное статическое приложение без backend, базы данных и авторизации.

## Состав проекта

- `index.html` — приложение целиком (HTML, CSS и JavaScript).

## Локальный запуск

Откройте `index.html` в современном браузере. Для чтения Excel подключается SheetJS с CDN, поэтому при первом запуске требуется интернет-соединение.

## Публикация

Проект является статическим сайтом. Для публикации загрузите `index.html` в корень GitHub-репозитория. При подключении репозитория к хостингу укажите корневую папку проекта; команда сборки и папка сборки не требуются.

## Конфиденциальность

Файл с данными обрабатывается в браузере пользователя. Приложение не содержит кода отправки загруженной таблицы на сервер и не использует базу данных. Для загрузки библиотеки SheetJS используется CDN; содержимое пользовательского файла туда не отправляется.


## Дополнительный расчет расходов на доставку

Для расчета требуется столбец `Dostavka_StoimostjhPolnaja`. В итогах показывается суммарная стоимость доставки по заказам, сумма чека которых равна порогу бесплатной доставки или превышает его (с учетом округления до `*990`, если оно включено). В таблицу и CSV также добавлен исходный столбец стоимости доставки.
